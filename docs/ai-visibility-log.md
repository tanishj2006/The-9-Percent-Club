# AI visibility log

A fixed set of 20 questions, asked every four weeks, to see whether answer
engines cite the site. Record what happened. Do not change the questions:
the point is to compare like with like over time.

**How to run it.** Use a logged-out or fresh session for each engine, with
location set to India where the engine allows. For each query, note whether
the site is cited (link or name), which URL, and whether the figure quoted
matches the site. "Cited" means a link or the name *The 9% Club*; a figure
alone without attribution counts as "no".

Engines: ChatGPT (search on), Perplexity, Google AI Overviews / AI Mode,
Gemini, Copilot, Claude (web search on).
